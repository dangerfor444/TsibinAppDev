# Трекер привычек

Этот API помогает управлять личными привычками и задавать дневные или недельные цели.

| Запрос | Что делает |
| --- | --- |
| `GET /habits` | Получает список моих привычек |
| `GET /habits/{habitId}` | Получает одну привычку по её ID |
| `POST /habits` | Создаёт привычку |
| `PUT /habits/{habitId}` | Заменяет настройки привычки |
| `DELETE /habits/{habitId}` | Удаляет привычку |

Я попросил Codex (модель `gpt-6-astra`) описать эти операции в OpenAPI 3.0, выделить схемы DTO и сгенерировать каркас на Spring.

После первой генерации я с помощью агента вручную поправил шаблон проверки названия в `api.yaml`, чтобы он принимал названия вроде «Читать 20 минут» и отклонял строки из одних пробелов. Затем я проверил спецификацию и повторил генерацию каркаса через OpenAPI Generator 7.26.0.
